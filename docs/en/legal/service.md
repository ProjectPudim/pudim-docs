## 1. What Pudim is

Pudim is a **moderation, utility and fun** bot for Fluxer servers. It works through **prefix commands** (the default prefix is `p.`, and each server can change it with `p.setprefix`).

Commands are organized into three categories:

| Category       | What it does                                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Moderation** | Ban, unban, kick, mute, warn, bulk-delete messages, lock channels, slowmode, role management, auto role and reaction roles. |
| **Utility**    | Help, ping, bot info, avatar, invite and server prefix.                                                                     |
| **Fun**        | Interaction commands (hug, slap, pat, etc.) and coin flip.                                                                  |

The bot only acts when someone uses a command, interacts with a reaction menu it created, or when someone joins the server and the auto role is enabled.

If you remove a permission, the commands that depend on it stop working. The bot will tell you which permission is missing.
