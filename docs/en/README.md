# Welcome!

Hi! I'm **Pudim**, a **moderation, utility and fun** bot for Fluxer communities.

Here you'll find everything you need to add Pudim to your server and get the most out of every command.

## Getting started

1. **Add Pudim to your server** using the [invite link](https://web.fluxer.app/oauth2/authorize?client_id=1562641741457141760&scope=bot&permissions=1099914669142).
2. **Run `p.help`** to see all commands. The default prefix is `p.`.
3. **Change the prefix** if you like, with `p.setprefix`.
4. Need help? Join the [support server](https://fluxer.gg/Ka4CXOqj).

You can also mention me (`@Pudim`) to see your server's prefix.

## What Pudim does

### Moderation

Tools to keep your community safe and organized.

| Feature | Commands |
| --- | --- |
| Punishments | `ban`, `unban`, `softban`, `massban`, `kick`, `mute`, `unmute` |
| Warnings | `warn`, `warnings`, `unwarn`, `clearwarns` |
| Channels | `purge`, `lock`, `unlock`, `slowmode` |
| Roles | `addrole`, `removerole`, `massrole`, `autorole`, `reactionroles` |
| Members | `nick` |

### Utility

`help`, `ping`, `botinfo`, `avatar`, `botinvite`, `setprefix`

### Fun

`hug`, `pat`, `kiss`, `slap`, `poke`, `punch`, `bonk`, `feed`, `wave`, `yeet`, `coinflip`

## Bot permissions

Pudim **does not need the Administrator permission**. The invite link above only requests the permissions the bot actually uses. If you remove one, only the commands that depend on it stop working, and the bot tells you which permission is missing.

For the role commands to work, Pudim's role must be **above** the roles it will manage in your server's role list.

## Privacy and terms

We're transparent about the data we use. Before using the bot, please read:

- [Terms of Service](legal/service.md)
- [Privacy Policy](legal/privacy.md)
