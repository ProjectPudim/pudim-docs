# Seja bem-vindo!

Oi! Eu sou o **Pudim**, um bot de **moderação, utilidades e diversão** para servidores do Fluxer.

Aqui você encontra tudo o que precisa para colocar o Pudim no seu servidor e aproveitar cada comando.

## Primeiros passos

1. **Adicione o Pudim ao seu servidor** pelo [link de convite](https://web.fluxer.app/oauth2/authorize?client_id=1562641741457141760\&scope=bot\&permissions=1099914669142).
2. **Use `p.help`** para ver todos os comandos. O prefixo padrão é `p.`.
3. **Mude o prefixo**, se quiser, com `p.setprefix`.
4. Precisa de ajuda? Entre no [servidor de suporte](https://fluxer.gg/Ka4CXOqj).

Você também pode me mencionar (`@Pudim`) para ver o prefixo do servidor.

## O que o Pudim faz

### Moderação

Ferramentas para manter a comunidade segura e organizada.

| Recurso      | Comandos                                                         |
| ------------ | ---------------------------------------------------------------- |
| Punições     | `ban`, `unban`, `softban`, `massban`, `kick`, `mute`, `unmute`   |
| Advertências | `warn`, `warnings`, `unwarn`, `clearwarns`                       |
| Canais       | `purge`, `lock`, `unlock`, `slowmode`                            |
| Cargos       | `addrole`, `removerole`, `massrole`, `autorole`, `reactionroles` |
| Membros      | `nick`                                                           |

### Utilidade

`help`, `ping`, `botinfo`, `avatar`, `botinvite`, `setprefix`

### Diversão

`hug`, `pat`, `kiss`, `slap`, `poke`, `punch`, `bonk`, `feed`, `wave`, `yeet`, `coinflip`

## Permissões do bot

O Pudim **não precisa do cargo de Administrador**. O link de convite acima já pede apenas as permissões que o bot usa. Se você remover alguma delas, só os comandos que dependem dela deixam de funcionar, e o bot avisa qual permissão está faltando.

Para os comandos de cargos funcionarem, o cargo do Pudim precisa ficar **acima** dos cargos que ele vai gerenciar na lista de cargos do servidor.

## Privacidade e termos

Somos transparentes sobre os dados que usamos. Antes de usar o bot, leia:

* [Termos de Serviço](legal/service.md)
* [Política de Privacidade](legal/privacy.md)

Em resumo: o Pudim lê mensagens só para detectar comandos, **não guarda o conteúdo delas**, não envia DMs e não usa voz.

## Precisa de ajuda?

Entre no nosso [servidor de suporte](https://fluxer.gg/Ka4CXOqj) para tirar dúvidas, reportar problemas ou pedir a remoção de dados.
